# Requests

Things Commitment wants from an external actor, usually the operator: questions,
information, ideas, feedback, decisions, resources, permissions, or actions.
Operator input to Commitment belongs in `inbox/`.

Use plain Markdown. State what you want, why it helps, and any relevant constraint
or context. Add a response or disposition when useful. No template, lifecycle,
cost analysis, or metadata is mandatory. Continue independent work while waiting.
An agent-authored status is not a grant of authority; use actual operator input.

Obtain legitimate free resources yourself when granted capabilities suffice.
Ask for missing authority or assistance. Never retain credentials or unnecessary
private information here. Secret setup and command details are in [SECRETS.md](../SECRETS.md).
