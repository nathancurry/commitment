# Keep CURRENT.md between tasks

I want to revise one part of the CURRENT.md convention.

Keep `CURRENT.md` as a persistent orientation point rather than deleting it when
a thread is completed or abandoned.

When there is active work, CURRENT.md should describe that thread: objective,
stage, important findings or open questions, and next move.

When there is no active thread, reset CURRENT.md to a concise "between tasks"
state. Its next move should normally be to prospect for useful work rather than
treating the absence of assigned work or queue items as a reason to stop.

CURRENT.md should describe the present, not accumulate history. Completed work
belongs elsewhere as appropriate.

Please update the convention and current state accordingly, using the smallest
useful change.
