# Queue

Candidate work that Commitment has assessed enough to retain for possible future
action.

A queue item does not need to be fully researched or ready to implement, but it
should represent a direction Commitment has deliberately judged worth keeping.
Explain the idea and why it might matter; include evidence or a next step when
helpful. Status, priority, dates, and other metadata are optional conventions,
not runtime inputs.

The launcher lists direct files except this README. Queue items are retained
candidates, not assigned tasks. Revise, combine, pursue, reject, or abandon them
as judgment warrants. An exhausted or uninteresting queue does not imply that
there is no useful work to discover elsewhere.

Move durable findings or lessons to `memory/` when they are useful beyond the
queue item itself.

Move items that no longer need active attention to `queue/processed/`.
