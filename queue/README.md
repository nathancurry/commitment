# Queue

Possible work, in useful Markdown. Explain an idea and why it might matter;
include evidence or a next step when helpful. Status, priority, dates, and
other metadata are optional conventions for the model, not runtime inputs.

The launcher lists direct files except this README. Their presence never
requires action or prevents NOOP. Revise, combine, reject, or abandon ideas
as judgment warrants. Leave useful findings when they will help a future session.
